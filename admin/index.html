Set up the site editor

This happens once. You give the editor a GitHub key that can only change this website, and protect it with your own password.

  1. Create the GitHub key. Under Repository access pick Only select repositories and choose abhiimhere.github.io. Under Permissions, set Contents to Read and write. Then generate it and copy it.
  2. Paste it below and choose a password of at least 12 characters.
